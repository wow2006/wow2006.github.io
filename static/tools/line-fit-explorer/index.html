Each pink segment is the residual rᵢ = hᵢ(x) − zᵢ, with hᵢ(x) = a tᵢ + b. The cost is F(x) = ½ Σ (rᵢ/σᵢ)². A trusted point has σᵢ = 1 (weight 1); a noisy one has σᵢ = 5 (weight 1/25), so the same residual's square counts 25 times less.

  1. Move the sliders to make F(x) as small as you can. You cannot go below the dashed best line: it is the minimum.
  2. Press “Show true line”. Its cost (2.2048) is higher than the best (2.1610): the best line fits this noise, not the truth.
  3. Press “Add a faulty reading”. One bad point drags the best line toward it.
  4. Click that point to mark it as noisy (σ = 5, weight 1/25). Its squared residual counts 25 times less, and the best line comes back.
